# D2 — «игровой чат» в MAX: протокол, карточки, таблица правды

**Статус на 23.09.2026: сессия не проводилась** (ответ владельца: добровольцев
24.09 не будет). Материалы подготовлены для финала; оценка P6 идёт без D2, её
контроль — синтетика (D3 holdout и D5).

## Файлы

| Файл | Что это |
|---|---|
| `cards.v1.md` | Карточки участников P01–P12 по минутам для двух сессий (S1, S2) и список инцидентов для ведущего |
| `truth.v1.jsonl` | Таблица правды: карточка → ожидаемая роль реплики и инцидент; инцидент → подтип, территория, подъезд, опасность, ожидаемый `route_type` |
| `../../evaluation/d2_convert.py` | Выгрузка сессии → строки формата D3 для `evaluation/p6_eval.py` |

Типы карточек (дополнение №2 §5): «пожалуйся как обычно», «поддержи»,
«уточни», «спроси, когда починят», «возрази», «ответь одним словом»,
«новость про другой район», «продай коляску», «спроси про квитанцию»,
«пошути». В каждой сессии 6 инцидентов, в том числе газ или дым (правила) и
одна опасность без ключевых слов (контекстная).

## Протокол сессии (40 минут)

1. За день: согласие участников на участие и на выгрузку их реплик из тестового
   чата для оценки; каждому — только его карточки.
2. Ведущий включает чтение тестового чата TEST_MAX (продукт P4) и отмечает
   время начала.
3. Участники пишут по карточкам **своими словами**; реальные адреса, имена,
   телефоны и номера квартир запрещены. Отвечать на реплики других можно и
   нужно; лишние реплики допустимы.
4. Ведущий ведёт соответствие «псевдоним буфера → P01…P12» в локальном файле
   `aliases.json` (в git не кладётся).
5. После сессии разработчик продукта делает read-only выгрузку реплик сессии
   из буфера (≤ 72 ч) в формате ниже; разработчик ML запускает конвертер и
   оценку.

## Формат выгрузки (P7b → разработчик ML)

JSONL, одна строка на реплику, без идентификаторов MAX и людей:

```json
{"session": "S1", "mid": "h:3f2a…", "sent_at": "2026-09-24T19:05:12+03:00",
 "author": "A", "reply_to": "h:91c0…", "text": "…", "synthetic": true,
 "origin": "d2_roleplay"}
```

`mid` и `reply_to` — хэши, `author` — псевдоним буфера. Строки без
`synthetic: true` конвертер отвергает.

## Оценка

```bash
uv run python evaluation/d2_convert.py export.jsonl aliases.json --out datasets/synthetic/d2_dialogs.v1.jsonl
uv run python evaluation/p6_eval.py --dataset d2 --config <итоговая> --run d2-<дата>
uv run python evaluation/p6_eval.py --dataset d2 --config rules --run d2-<дата>-rules
```
