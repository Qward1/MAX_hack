# ДомСигнал — Smoke / Demo Readiness

**Отвечает на вопрос:** можно ли прямо сейчас показывать систему комиссии.
**Время прогона:** 45–60 минут.
**Когда проводить:** перед каждой демонстрацией, после каждой выкладки и в первый день периода проверки жюри.
**Версия набора:** 1.1 от 29.09.2026.

Подробные шаги, адреса и тексты — в [`TEST_CASES.md`](TEST_CASES.md): у каждой проверки указан полный тест-кейс. Здесь — сокращённая форма для быстрого прогона.

## Решение Go / No-Go

| Итог | Условие |
|---|---|
| **GO** | SM-01…SM-13, SM-15 и SM-17 — PASS |
| **GO с оговоркой** | Упала только SM-14 или SM-16. Показ возможен, но исправить до периода проверки |
| **NO-GO** | Упала любая из SM-01, SM-02, SM-04, SM-06, SM-07, SM-08, SM-09, SM-10, SM-11, SM-17. Показывать нельзя; восстановление витрины — [`docs/RELEASE.md`](../RELEASE.md) |

**Что проверяется только вручную:** «Открыть» у поста заявки и «Голосовать» у опроса — живые шаги в клиенте MAX (способ human-MAX в [матрице приёмки](ACCEPTANCE_MATRIX.md)).
